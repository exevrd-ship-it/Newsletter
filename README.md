# The Sunday Ledger

Website for a free weekly newsletter on the world economy, published every Sunday morning.

**➡️ Pour personnaliser le site et le mettre en ligne, suis le [GUIDE.md](GUIDE.md).**

- All personal information lives in [`config.js`](config.js).
- Static site (HTML/CSS/JS, no dependencies), published on GitHub Pages via `.github/workflows/deploy.yml`.
- Preview locally: open `index.html` in a browser.
